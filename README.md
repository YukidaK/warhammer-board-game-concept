# warhammer-board-game-concept

## Executar

Abra esta pasta como projeto no Unity Hub e aguarde a importação. No editor,
clique em **Play** e abra a aba **Game**.

O script `Assets/Editor/CenaInicial.cs` configura automaticamente
`Assets/Scenes/Batalha.unity` como cena inicial do Play, mesmo quando outra
cena está aberta. Essa configuração acompanha o repositório, sem depender
das preferências locais do editor.

O mapa, as unidades e a interface são criados durante a execução da partida.
